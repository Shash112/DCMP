# DCMP End-to-End (E2E) Tests

**Governing Document:** `docs/DCMP_Detailed_Test_Plan_and_Test_Cases_v1.0.docx` Section 14

## Test Scope

End-to-end tests exercise complete user journeys:

1. **Platform Administrator Journey:** Tenant creation, license provisioning, device activation key generation.
2. **Customer Admin Journey:** Subdomain login, branding customization, location and department setup, checklist authoring, inspector assignment.
3. **Inspector Mobile Journey:** Device activation, login, assigned checklist execution, photo evidence capture, draft saving, submission, offline queue synchronization.
4. **Supervisor Approval Journey:** Submitted inspection review, approval or rejection with corrective action dispatch.
